# 朋友圈文案生成器（Claude Code Skill）

一套"高拟真、反AI检测"的个人朋友圈文案生成 skill。你说出想发的核心思想 + 配图/场景，它从内置的风格方法论库里匹配最贴切的写法，给你 **top3 候选**（每条带骨架说明 + 更狠版/更温和版 + 1 条评论区补刀），你挑一条自己发。

## 安装
把整个 `ks-pyqwa` 文件夹拷到你的 Claude Code skills 目录：

- 全局可用：`~/.claude/skills/ks-pyqwa/`
- 或仅某项目可用：`<项目>/.claude/skills/ks-pyqwa/`

目录结构（拷过去后应是这样）：
```
ks-pyqwa/
├── SKILL.md
├── README.md
└── knowledge/
    └── 朋友圈文案方法论.md
```

装好后在 Claude Code 里直接说"我想发个朋友圈……"或输入 `/ks-pyqwa` 即可触发。

## 怎么用
直接说你想发什么，给上：
1. **核心思想**（必需）：这条想表达啥，一句话。
2. **素材/场景**：配几张图、图里是什么、有无定位/人物/具体物件/数字。
3. **力度**（可选）：轻松 / 中 / 犀利 / 很冲。
4. **禁区**（可选）：不想出现的词、不想带 emoji 等。

## 个性化（建议先做一次）
`knowledge/朋友圈文案方法论.md` 顶部的「账号画像」是一个**虚构示范**。把它改成你自己的真实人设（性别 / 城市 / 职业 / 家庭 / 常发什么），生成的文案才贴合你本人。下面的骨架 A~N、方法论、反检测策略是通用的，不用改。

想更进一步：每积累一批自己的真实朋友圈，把新出现的写法补进第 2 节样本和第 4.1 节骨架，这个 skill 会越用越像你。
